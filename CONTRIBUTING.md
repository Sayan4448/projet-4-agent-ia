# Contribuer

Voir [le guide de développement](docs/DEVELOPPEMENT.md) pour ouvrir, tester et compiler
le projet. Pour signaler un bug, préciser Windows, version de l’app, mode, fournisseur,
modèle, message exact et étapes de reproduction. Masquer les clés et données personnelles.

Pour une modification : créer une branche, limiter le changement au problème visé,
ajouter une régression utile puis exécuter les tests Windows. Les changements sur les
coordonnées, l’arrêt et l’isolation du navigateur doivent conserver leurs garanties.

La publication publique ne constitue pas à elle seule une licence open source.
Aucune licence de redistribution générale n’est encore choisie pour le code propre
au projet ; les dépendances conservent leurs licences respectives.
